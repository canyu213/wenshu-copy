# 知识组织规范 · R2（文枢 references/）

> **定位**：领域库怎么分层、知识怎么组织。定义文枢"知识库结构模式"——任何学科领域库按同一套结构逻辑搭建。
> **底稿来源**：文枢知识库《重建指南》§1/§4 + 《00_总导航》（九子库 + 七级链路实战验证）
> **通用化原则**：把"九子库"提炼为通用"领域库分层模式"；标签四组模式通用，C 组按学科替换。
> **AI 可对接**：本规范可直接被 agent 读取执行，指导领域库搭建。

---

## 1. 设计原则

| 原则 | 说明 |
|---|---|
| **脉络优先** | 知识按"学科演进脉络"分层组织（源头→发展→当代→政策→研究→工具），不是平铺 |
| **段落级精准引用** | 全库锚点化（见 R3），支持 `[[文件#^blockID]]` 精准跳转 |
| **双向索引** | `related_*` 入链 + `cited_by` 反链，构建跨库引用网络 |
| **加法不替换** | 标签/元数据叠加在已有内容之上，不删除现有数据 |
| **AI 可对接** | 核心规范写入"对接指南"式文档，新 AI 工具接入必读 |
| **工程化思维** | 脚本自动化 > 手动操作，每步有验证（dry-run / 冒烟测试 / 批后报告） |
| **增量迭代** | 不追求一次完美，按 P0/P1/P2 分级持续推进（见 R6 领域适配） |

---

## 2. 子库结构模式（通用领域库分层）

从人文社科知识库实例提炼的通用分层法——**任何学科领域库按此模式搭建**：

```
<领域>知识库/
├── 00_总导航.md                    ← 统一入口（人读）
├── 00_对接指南.md                  ← AI 必读（含同步脚本维护）
├── 01_<学科源头文献>/              ← 奠基性原典（如学科奠基原典）
├── 02_<理论演进文献>/              ← 后继发展（如后继经典）
├── 03_<当代理论文献>/              ← 当代主流理论
├── 04_<并行支线>/                  ← 国外/批判/跨学科视角
├── 05_<政策与制度>/                ← 政策文件/制度规范
├── 06_<研究文献>/                  ← 学术论文（研究层）
├── 07_<工具书>/                    ← 辞典/术语表（概念锚点）
├── 70_模板/                        ← 笔记模板
├── 90_阅读笔记/                    ← 个人积累层
├── 99_写作辅助/                    ← 写作工具
├── _build/                         ← 构建脚本
└── 修改记录/                       ← 方案/日志/待入库
```

**分层逻辑**：每一层是学科脉络中的一个环节，支持跨层链路贯通查询。

## 3. 标签体系（四组模式）

每个条目打标签时按四组各选：

### A 组 · 脉络定位（选 1）——回答"属于哪个思想/理论传统"
| 标签 | 适用范围 |
|---|---|
| `#<学科经典>` | 源头+发展层文献 |
| `#<学科中国化/本土化>` | 当代层文献 |
| `#<国外视角>` | 并行支线 |
| `#<历史>` | 政策层中的历史部分 |

### B 组 · 文献类型（选 1-2）——回答"这是什么"
| 标签 | 适用范围 |
|---|---|
| `#原著` | 经典著作原文 |
| `#学术论文` | 研究文献 |
| `#政策文件` | 政策制度文件 |
| `#词条` | 工具书条目 |

### C 组 · 学科领域（可选，最多 3）——回答"属于哪个研究方向"
按具体学科定义（C 组示例：`#哲学` `#教育学` `#文化研究`）。

### D 组 · 状态标记（可选 1）
| 标签 | 用途 |
|---|---|
| `#待读` | 已入库未阅读 |
| `#精读` | 已深度阅读有批注 |

**叠加规则**：每个文件至少挂 A 组 1 个 + B 组 1 个，建议加 C 组 1-2 个。

**格式规范**：
- YAML 多行列表不带 `#`，Markdown 引用时用 `#标签名`
- **核心范畴不得缩写**：`思想政治教育` 不写 `思政`；任意简写 → 全称

## 4. 跨库链接设计

### 4.1 链接类型

| 链接 | 类型 | 说明 |
|---|---|---|
| `related_classics` | 入链 | 引用经典/源头文献（`[[文件#^blockID]]`） |
| `related_policy` | 入链 | 关联政策/制度文件 |
| `related_concepts` | 入链 | 关联概念/词条 |
| `cited_by` | 反链 | 被谁引用（**脚本自动维护**） |
| 桥梁链接 | 双向 | 跨层之间的显式桥（如"研究→源头"） |

### 4.2 链接注入等级

| 等级 | 方式 | 说明 | 实现 |
|---|---|---|---|
| L0 | 目录种子注入 | 按文件所在目录映射，自动注入 | 参考设计（个人库 post_import_hook），未内置 |
| L1 | 关键词语义匹配 | 按术语表匹配关键词注入 | `scripts/link_inject.py`（--map 映射表） |
| L2 | 反向回填 | `cited_by` 由脚本批量回填 | `scripts/cited_by_backfill.py` |
| L3 | 人工/语义补充 | 深度语义关联，AI 辅助补充 | agent 对话完成 |

### 4.3 链路贯通

任意节点支持 `[[文件#^blockID]]` 段落级跳转 + `cited_by` 反向溯源，形成"从头到尾可追踪"的链路。

## 5. 脉络链路模式

### 5.1 学科脉络链路

```
源头(01) → 发展(02) → 当代(03) → 政策(05) → 研究(06)
  │         │         │          │          │
  └───────┴───────┴───────←───工具书(07，概念锚点)
```

### 5.2 实例：理论演进七级链路

```
源头原典 → 理论演进 → 当代发展 → 应用实践 → 研究论文
  │      │      │      │       │        │      │
  └──────┴──────┴──────┴───────┴────←───辞典（概念锚点）
```

**规则**：回答研究类问题必须按脉络链路组织内容，从源头回溯到当代。

---

## 6. 操作纪律

1. **先 dry-run 再执行**：所有批量写入脚本先 `--dry-run`
2. **冒烟测试**：新脚本先在小子集上验证，再扩展全库
3. **批后报告**：每次批量操作生成 `{action}_report_{date}.md`
4. **不跳上游**：构建流水线按顺序执行，不跳过上游直接跑下游
5. **核心规范同步**：对接指南类文档每次库结构变更后运行同步脚本更新

## 7. 领域适配说明

| 项 | 通用处理 |
|---|---|
| 子库结构 | 按 §2 分层模式替换为具体学科 |
| 标签 A 组 | 按学科脉络替换 |
| 标签 C 组 | 按学科领域定义 |
| 跨库映射表 | 按领域"子目录→源头/政策"映射表配置（L0 注入用） |

> 实例：文枢知识库的九子库 + 七级链路即本规范的"已启用版"（详见《00_总导航》）。
