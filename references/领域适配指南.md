# 领域适配指南 · R6（文枢 references/）

> **定位**：文枢 skill 从"马克思主义实例"扩展到其他学科的方法论。定义领域库构建流程、领域层替换清单与迭代维护协议。
> **底稿来源**：马克思主义知识库《重建指南》§1.3（P0-P7 阶段）+ §6（维护协议）+ 附录 D（跨库映射表）
> **通用化原则**：P0-P7 阶段模式通用，可作为任何学科的施工模板；马克思主义实例作为"如何构建一个领域库"的完整演示。
> **AI 可对接**：本指南可直接被 agent 读取执行，指导新领域库从零搭建。

## 1. 领域库构建流程（P0-P7 阶段模式）

从马克思主义知识库 12 天建设经验提炼的通用阶段：

| 阶段 | 核心任务 | 标志性成果 |
|:----:|----------|-----------|
| **P0 基建** | 核心子库基础建设（源头文献 + 工具书） | 原著全文提取、基础 YAML 注入 |
| **P1 扩展** | 实践驱动扩展（使用反馈推动） | 工作流定型、备忘录 |
| **P2 全量** | 全量子库建设 + 元数据补录 | 元数据补录、跨库链接注入 |
| **P3 升级** | 结构重构 + 新资源入库 | 目录重构、统一入库脚本 |
| **P4 加固** | 跨库链接重建 + 资源扩展 | 链接重建、子库扩充 |
| **P5 深化** | 使用场景驱动深化 | 引文系统调取、精读、OCR 管线 |
| **P6 精细** | 研究路径深化 + 工具完善 | 交叉分析、Skill 完善 |
| **P7 文档化** | 全流程回顾 + 文档沉淀 | 重建指南/对接指南生成 |

**关键经验**：
- 每天 1-2 项 P0 任务持续进步，不追求一次完美
- 脚本自动化 > 手动操作，每步有验证
- 按"使用驱动"而非"规划驱动"迭代（P1/P5 都是使用反馈推动）

## 3. 实例演示：马克思主义知识库怎么建的

作为"如何构建一个领域库"的完整示范（12 天，P0-P7）：

| 维度 | 实例 |
|---|---|
| 规模 | 九子库，约 5,660 篇 |
| 结构 | 马恩→列宁→毛选→中特→新思想→西马→时政→论文→辞典 |
| 锚点 | 65 万+ Block ID，8 套命名空间 |
| 关联 | 辞典→原著 2,566 条 wikilink；论文→经典/政策数百条 |
| 自动化 | 60+ 构建脚本（入库/巡检/死链/标签/快照） |
| 文档 | AI 对接指南 + 重建指南 + 总导航 |
| 维护 | 每日自动化（快照/健康检查/待入库扫描） |

**可复用资产**（文枢已提炼为 references/）：
- 元数据方案（R1）——字段体系实战验证
- 知识组织规范（R2）——九子库/标签/链接模式
- 段落锚点规范（R3）——Block ID 体系
- 引文规范（R4）——国标引文 + 核验排版分离
- 入库规范（R5）——unified_import 流水线

## 4. 迭代维护协议

### 4.1 P0/P1/P2 分级待办

| 等级 | 时间框架 | 说明 |
|:----:|:--------:|------|
| P0 | 本周 | 阻断性问题（编码乱码、空壳文件、死链） |
| P1 | 两周 | 效率问题（元数据缺失、分类不完整） |
| P2 | 一个月 | 增强问题（新资源入库、功能扩展） |

### 4.2 每日自动化任务

1. 扫描"修改记录"的新增/更新
2. 验证 P0/P1/P2 闭环进度
3. 检查"待入库"区有待处理文件
4. 全库健康检查（YAML 巡检 + 死链检测 + 标签合规）
5. 生成日快照 + 差异检测
6. 产出当日优化报告

### 4.3 增量维护协议

- 新内容走"待入库 → 处理 → 归档"流程（不直接写库）
- 入库自动触发 L0 链接注入（post_import_hook）
- 文档同步（对接指南/总导航）随库结构变更自动更新

## 5. 新领域启用检查单（AI 执行）

```
□ 1. 建目录：按 R2 §2 分层模式建领域库骨架
□ 2. 建模板：按领域文献类型设计 2-4 个笔记模板（R5 §2）
□ 3. 配标签：定义 A 组（脉络）+ C 组（学科领域）（R2 §3）
□ 4. 配映射：配置 L0 跨库映射表（R5 §5）
□ 5. 设锚点：为子库分配 Block ID 前缀（R3 §2）
□ 6. 导入首批文献：走 R5 入库流水线
□ 7. 质量门：YAML 巡检 + 死链 + 标签合规全通过
□ 8. 写对接指南：生成领域库 AI 对接文档（含同步脚本）
```
