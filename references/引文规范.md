# 引文规范 · R4（文枢 references/）

> **定位**：国标引文格式的权威规则 + 格式化实现指引。任何学科领域库的引文输出遵循同一套规则。
> **底稿来源**：chinese-reference-formatter-skill 规则清单（GB/T 7714 通用版）+ biblatex-gb7714-2025（2025 新版差异）+ 马克思主义知识库《重建指南》§5.3（引用实践口径）
> **通用化原则**：以 GB/T 7714-2025 为权威标准，剥离学科专属引用习惯。
> **AI 可对接**：本规范可直接被 agent 读取执行，指导引文核验、格式化与输出。

## 2. 主要著录格式

统一以 `[序号]` 为前缀。以下为 GB/T 7714 通用格式：

| 类型 | 格式 |
|---|---|
| 期刊 | `[序号] 作者. 题名[J]. 期刊名, 年, 卷(期):页码.` |
| 会议 | `[序号] 作者. 题名[C]//会议录或论文集名. 出版地:出版者, 出版年:页码.` |
| 图书 | `[序号] 作者. 书名[M]. 版本项. 出版地:出版社, 出版年:页码.` |
| 析出章节 | `[序号] 析出作者. 析出题名[类型]//专著作者. 专著题名. 出版地:出版者, 出版年:页码.` |
| 学位论文 | `[序号] 作者. 题名[D]. 保存地:保存单位, 年份:页码.` |
| 报告 | `[序号] 作者. 题名[R]. 出版地或保存地:机构, 年份:页码.` |
| 标准 | `[序号] 起草责任者. 标准编号. 标准名称[S]. 出版地:出版者, 出版年.` |
| 专利 | `[序号] 专利申请者. 专利题名[P]. 国别, 专利号. 发布日期.` |
| 报纸 | `[序号] 作者. 题名[N]. 报纸名, 年-月-日(版次).` |
| 在线 | `[序号] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.` |

---

## 3. 作者与语言规则

| 规则 | 说明 |
|---|---|
| 作者数量 | ≤3 名全部列出；>3 名中文用"等"、英文用"et al" |
| 中文作者 | 按原文保留 |
| 西文作者 | 姓在前、名缩写在后，缩写不带点：`Einstein A` |
| 英文题名 | 首词与专有名词大写，停用词（of/the/and 等）小写 |
| 翻译 | 题名与作者名默认不翻译 |

## 4. GB/T 7714-2025 新变化（对照 2015）

> 来源：biblatex-gb7714-2025（国标 2025 实现的官方说明）

| 变化 | 说明 |
|---|---|
| **新增预印本类型** | 预印本可作为独立类型著录 |
| **著录类型细化** | 一些文献按图书、图书析出、期刊析出等类型分别著录 |
| **日期处理差异** | 非 online 类的访问日期不输出；online 类日期与标点在不同情况下有差异；档案形成日期在不同情况下有差异 |
| **全角标点的引入** | 2025 版引入全角标点规范（与 2015 版差异明显） |

> ⚠️ 文枢引文引擎应以 **GB/T 7714-2025** 为规则基准；同时兼容 2015 版输出（用户要求时）。

## 5. 引用格式（衔接 R3 段落锚点）

### 5.1 库内引用

```markdown
> 引文内容……
> ——《著作名》，第X卷，第Y页
> [[文件名#^blockID]]
```

### 5.2 论文正文引用（投稿格式）

按 GB/T 7714 数值引文：正文标注 `[1]`，文末按序排列文献表（见 §2 著录格式）。

### 5.3 规则

1. 引文必须可溯源（锚点 / 出处 / 页码）
2. 无页码标 `[页码待查]`，禁止编造
3. 文献表按正文引用顺序编号

## 6. 格式化实现指引（核验与排版分离）

文枢引文引擎采用两阶段架构（借鉴 chinese-reference-formatter-skill，MIT 可复用）：

```
输入题名/文献
  → ① 核验阶段（agent + API 模型）：检索公开元数据，比对题名/作者/年份/载体/DOI
  → ② 排版阶段（确定性脚本）：把核验通过的元数据 JSON 渲染成国标引文
```

### 6.1 核验阶段规则

| 规则 | 说明 |
|---|---|
| 不凭题名猜测 | 查不到就输出"未找到"，不编造 |
| 来源优先级 | DOI/官方页面/出版社/标准机构 > 聚合站 |
| 冲突处理 | 多来源冲突且无法判定权威时，明确报歧义，不替用户选 |
| 预印本 | 仅当用户要求或正式版不存在时采用 |

### 6.2 排版阶段

- 复用 `format_reference.py`（MIT，纯 Python 标准库，支持 10 种类型 + BibTeX）
- 元数据以标准化 JSON 为中间接口：`{type, title, authors, journal, year, volume, issue, pages, doi, url, sources}`
- 输出：国标引文 + BibTeX + 核验来源

---

## 7. 操作纪律（AI 必须遵守）

- ❌ 禁止凭题名猜测文献信息
- ❌ 禁止编造页码/作者/年份
- ❌ 禁止默认翻译题名或作者名
- ❌ 禁止把聚合站结果当权威来源
- ❌ 禁止强制学校/期刊特殊细则（除非用户明确提供）

> 一个引文工具最重要的能力不是"看起来格式对"，而是**知道什么时候不能确定**。

---

## 8. 领域适配说明

- 各学科引用习惯（如法学脚注制、心理学 APA）作为"领域扩展"，不改变核心国标规则
- 学科专属文献类型（如档案、法规）可扩展载体代码
- 库内引用统一用 §5.1 格式（锚点制），投稿格式用 §5.2
