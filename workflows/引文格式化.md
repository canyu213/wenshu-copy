# 工作流：引文格式化（文枢 workflows/）

> **目标**：把题名/文献信息核验并格式化为 GB/T 7714-2025 国标引文 + BibTeX，全程可溯源、不编造。
> **依赖**：R3 段落锚点规范 / R4 引文规范 / R1 元数据方案
> **执行方**：文枢 agent（智能体 + API 模型做核验判断），format_reference.py（确定性排版）。

---

## 1. 输入

- 文献题名 / 部分文献信息（作者/年份/期刊等，可不完整）

## 2. 执行步骤（核验与排版分离）

```
Step 1  读取规则：读取 R4 引文规范（GB/T 7714-2025 规则清单）
Step 2  核验来源：agent + API 模型检索公开元数据
        - 比对题名/作者/年份/载体/DOI/ISBN/URL
        - 来源优先级：DOI/官方页面/出版社/标准机构 > 聚合站
Step 3  解决冲突：
        - 官方版本 > 预印本
        - 多来源冲突且无法判定权威 → 报歧义，不替用户选
        - 找不到明确匹配 → 输出"未找到"，不编造
Step 4  标准化 JSON：核验通过的元数据 → {type, title, authors, journal, year, volume, issue, pages, doi, url, sources}
Step 5  确定性排版：format_reference.py 渲染（MIT 复用）
        - 输出：国标引文 + BibTeX + 核验来源
Step 6  锚点衔接：若文献在库内，引文附带 [[文件#^blockID]] 段落溯源（R3）
```

## 3. 输出

```
标准参考文献：[1] 作者. 题名[J]. 期刊名, 年, 卷(期):页码.
BibTeX：...
核验来源：...
（库内文献时附段落锚点）
```

## 4. 质量门

- [ ] 元数据已核验（有权威来源，非凭题名猜测）
- [ ] 页码/作者/年份真实（无编造）
- [ ] 冲突已按规则处理（官方>预印本；歧义已标注）
- [ ] 格式符合 GB/T 7714-2025
- [ ] 库内文献已附锚点

## 5. 操作纪律（合规红线）

1. 禁止凭题名猜测文献信息
2. 禁止编造页码/作者/年份
3. 禁止默认翻译题名/作者
4. 禁止强制学校/期刊特殊细则（除非用户提供）

> 引文工具的底线：**知道什么时候不能确定**。核验不过就明说。

## 6. 场景说明

- 用户给出题名 → 补全并格式化
- 从库内文献生成引文 → 直接格式化 + 附锚点
- 批量文献表 → 按引用顺序编号 [1][2][3]...
