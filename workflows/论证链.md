# 工作流：论证链（文枢 workflows/）

> **目标**：把文献中的论证结构抽取为"论点-证据链"——借鉴图尔敏模型，对段落做论点/论据/结论角色标注，支持"一证多引"论证组织。
> **依赖**：R1 元数据方案 / R3 段落锚点规范 / R4 引文规范
> **执行方**：文枢 agent（智能体 + API 模型做角色标注），确定性脚本做整理输出。
> **合规**：本工作流做"论证组织辅助"，不代写核心论点——论点/结论由研究者自己定，AI 只做抽取、组织与标注。

---

## 1. 输入

- 知识库文献（含段落锚点的全文）
- 用户需求（梳理某主题的论证/证据结构）

## 2. 图尔敏模型角色定义

对文献段落做角色标注：

| 角色 | 含义 | 示例 |
|---|---|---|
| **论点（Claim）** | 作者主张的结论 | "文化领导权是...的关键" |
| **论据（Data）** | 支持论点的证据/事实 | 文献引用、数据、原文依据 |
| **结论（Conclusion）** | 论证的落点/推论 | 由论点+论据推出的判断 |

**支撑关系**：支持（论据支撑论点）/ 反驳（某文献驳斥另一观点）/ 互补（多文献共同支撑同一论点）。

## 3. 执行步骤

```
Step 1  定位主题：确定要梳理的论证主题（用户指定）
Step 2  段落标注：agent + API 模型对相关段落做角色标注（论点/论据/结论）
        - 仅标注，不代写——研究者自定核心论点
Step 3  关系组织：标注段落间支撑/反驳/互补关系
        - 支持"一证多引"：同一论据被多篇文献支持/反驳
Step 4  关联引文：每个论据/论点附引文（R4 引文规范）+ 段落锚点（R3）
Step 5  整理输出：生成论证链清单（论点→论据→结论 + 来源）
```

## 4. 输出

```
论证链：[主题]
  论点：...（附锚点 + 引文）
  论据：
    - 论据1：... ← 文献A（锚点）
    - 论据2：... ← 文献B（锚点）
    - 反驳：... ← 文献C（锚点）
  结论：...（研究者定稿）
```

## 5. 质量门

- [ ] 角色标注与原文一致（无曲解）
- [ ] 每项论据/论点有锚点与引文
- [ ] 支持/反驳关系有文献依据
- [ ] **核心论点/结论由研究者定稿**（AI 仅组织，不代写）

## 6. 操作纪律（合规红线）

1. AI 只做抽取/组织/标注，**不代写研究假设、核心论点、结论**
2. 引文必须可溯源（锚点 + 核验），禁止编造
3. 反驳关系需有明确文献依据，不臆测
