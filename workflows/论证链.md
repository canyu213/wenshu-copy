# 工作流：论证链（ChatGPT）

## 目标
从已有文献中抽取并组织论点、证据、反驳和推论关系，帮助用户检查论证结构；不替用户生成研究假设、核心论点或最终结论。

## 执行

1. 以用户指定主题为范围；若主题已经明确，直接检索相关文献段落。
2. 对每个候选段落标注其论证角色：
   - Claim：作者明确主张。
   - Data/Evidence：事实、材料、数据、引文或其他支撑。
   - Warrant/Reasoning：从证据到主张的推理桥梁（仅在文本能支持时标注）。
   - Rebuttal：限制条件、反例、反驳或竞争解释。
   - Conclusion：文献作者明确给出的推论；不要把模型自己的总结冒充作者结论。
3. 关系只在有文本证据时标为支持、反驳、互补或限制。
4. 每个重要节点附实际文件/网页来源；已入库文献可同时附 Block ID。
5. 不同文献对同一命题有冲突时并列呈现，不替用户静默选择一方。

## 输出建议

按“命题 → 支持证据 → 推理桥梁 → 反驳/限制 → 来源”的结构输出。用户自己的核心论点可以作为待填的研究者节点，但不要自动替其定稿。

## 质量门

- 角色标注能回到原文核对。
- 证据与论点之间不是仅靠主题相似建立关系。
- 引用、页码、数据不编造。
- 文献作者的结论与模型的解释明确区分。
- 缺证据的关系标 `依据不足`，而不是补写。
