# 工作流：检索问答（文枢 workflows/）

> **目标**：在 md 知识库上做语义检索问答——向量召回 + 图谱增强 + 锚点溯源，回答可溯源、不编造。
> **依赖**：R3 段落锚点规范 / R4 引文规范 / `scripts/skill_rag.py`
> **执行方**：文枢 agent（智能体 + API 模型），脚本负责确定性操作。
> **设计**：模式 D（skill 原生 RAG）——不依赖 LightRAG 等外部框架，自研轻量版。

---

## 1. 三层架构

```
向量层（语义召回）
  锚点块 → embedding API → vectors.npy（numpy 本地余弦检索，毫秒级）
图谱层（跨篇增强）
  DeepSeek 逐篇抽取实体/关系 → concept_graph.json（独立产物，可增量）
问答层（组织回答）
  向量召回 top-k + 图谱关联上下文 → DeepSeek 组织回答 → 锚点引用
```

## 2. 执行步骤

```
Step 1  构建向量索引（一次性，新增文献后增量重跑）：
        python scripts/skill_rag.py --build --kb 知识库目录 --out 索引目录
        [--titles 篇1,篇2]     # 可选：只索引指定篇目

Step 2  构建谱系图谱（可选，跨篇问答增强）：
        python scripts/skill_rag.py --graph-build --kb ... --out ...
        → 产出 concept_graph.json（断点续跑，每篇落盘）

Step 3  问答：
        python scripts/skill_rag.py --query "问题" --kb ... --out ... [--top-k 8]
        → 输出：检索命中（top-k + 分数）+ 图谱关联（如有）+ 回答（带 [[路径#锚点]]）
```

## 3. 关键设计

| 设计 | 说明 |
|---|---|
| **向量层本地计算** | 余弦相似度用 numpy（2740 块×1024 维毫秒级），**不需要向量数据库** |
| **图谱三类关系** | source（源自）/ develop（发展）/ debate（对立批判）——对齐谱系图谱工作流；横向关系通过共享父节点传递 |
| **图谱独立产物** | `concept_graph.json` 可查可增量，未来可对照知识库 `cited_by`/wikilink |
| **锚点溯源** | 每个 chunk 带 `^v{卷}p{页码}` 锚点，回答引用 `[[路径#锚点]]` |

## 4. 质量门

- [ ] 索引构建：块数合理、无空块（`--build` 输出统计）
- [ ] 图谱抽取：实体真实存在、每条关系带 evidence（原文片段）
- [ ] 问答：回答引用锚点、不编造（prompt 硬约束 + 片段不足明说"依据有限"）
- [ ] 断点续跑：`graph_progress.json` 记录进度，失败可重跑

## 5. 操作纪律

1. 批量构建前先小样本验证（`--titles` 限 3-5 篇）
2. 图谱抽取失败自动重试 3 次，仍失败记录到日志不中断整体
3. .env 配置：`LLM_BINDING_*`（DeepSeek）+ `EMBEDDING_BINDING_*`（硅基流动 bge-m3）
4. 运行位置：在配置了 .env 的目录下运行（脚本显式加载 cwd 的 .env）

## 6. 与 references/ 的衔接

| 环节 | 规范 |
|---|---|
| 锚点块 | R3 段落锚点规范 |
| 引用格式 | R4 引文规范（回答引用锚点） |
| 关系原子 | 谱系图谱工作流（来源/发展/争论） |
| 图谱产物 | 可对照 R2 知识组织规范的 cited_by/wikilink |
