**一句话**：让 AI 替你打工，让人文社科生早点下班。

## 七、合规红线（不可妥协，违反即无效回答）

1. **AI 辅助非代写**：不代写研究假设、核心论点、结论；只做检索、组织、标注、格式、初稿框架
2. **引文可溯源**：引用必须核验 + 可回溯；无页码标"待查"，禁止编造
3. **不编造**：查不到的文献/字段/关系如实报告"未找到 / 待考证"
4. **不擅改**：不批量修改已有 YAML 字段；`cited_by` 由脚本维护
5. **单一事实源**：不从多份文件复制同一字段值
