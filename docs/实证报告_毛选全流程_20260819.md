## 二、入库环节（S1-S6）

| 环节 | 工具 | 关键数据 | 结果 |
|---|---|---|---|
| S1 提取 | pdf_extract.py | 1559 页全量，2 分 13 秒；空页率 0.1%，乱码率 0% | ✅ |
| S2 目录解析 | toc_parse.py（双通道） | **137 篇**（第一卷 17 / 第二卷 33 / 第三卷 31 / 第四卷 56）；单通道仅 46 篇 → 双通道提升约 3 倍 | ✅ |
| S3 偏移检测 | offset_detect.py（分段） | 各卷偏移 9 / 22 / 30 / 41，样本一致性 96%-100% | ✅ |
| S4 分篇切分 | split_works.py（卷感知） | 137 篇全部完成，93.5 万字，重叠/空块 0 | ✅ |
| S5 生成 md | kb_builder.py | 137 文件，1402 锚点（格式 `^v{卷2位}p{页码4位}`），YAML 元数据 | ✅ |
| S6 质量门 | quality_gate.py | 0 问题；抽样 14 篇（每卷 10%）人工验收通过 | ✅ |

**关键发现**（可复用方法论）：

1. **双通道目录解析**：单通道（仅目录页）在 OCR 差的书上只解析出 46/145 篇且篇名残缺；通道 B（正文标题页扫描）提供完整篇名，通道 A 只补页码范围——"B 为名、A 为范围"架构可复用。
2. **多卷本必须卷感知**：毛选每卷页码独立编号，偏移 9/22/30/41——分段检测 + 每卷独立偏移是通用多卷本的必备能力。
3. **跨行截断是长标题书通病**：18/137（13%）篇名被截断，内置"标题跨行拼接 + 质检补全"环节。

**修复记录**（S6 批量修复）：高频 OCR 错字 106 文件（间题→问题 644 处 / 衣民→农民 240 处 / 关千→关于 85 处）；跨行截断篇名 18 个（03 卡片交叉验证补全）；文件名对齐 8 个。

## 四、谱系图谱

**方法**：DeepSeek 自动抽取概念间三类关系（来源 source / 发展 develop / 争论 debate），每条关系附原文 evidence。

| 指标 | 值 | 说明 |
|---|---|---|
| 实体 | 1219（concept 757 / theory 131 / scholar 131 / work 141 / event 3，另 137 篇目自指） | 原始数据 `concept_graph.json` |
| 关系 | 1278（来源/发展/争论） | `concept_graph.json` |
| **evidence 完整率** | **100%** | 每条关系都有原文佐证 |
| 抽核 | 随机 5 条，与原文逐字吻合（5/5） | 如"马克思主义 -[debate]-> 主观主义"：*"主观主义、宗派主义和党八股，这三种东西，都是反马克思主义的"* |
| 孤立实体率 | 8.7% | 90%+ 实体有连接 |
| 篇目覆盖 | 137/137 | 篇目自指兜底 |
| 可视化 | 1275 节点 / 1278 边 | `three_data.json` → galaxy 3D 演示 |

**与人工知识库互补**：知识库 `cited_by` 是"论文→著作"横向引用网络（人工构建）；图谱是"著作内概念→概念"纵向思想谱系（AI 抽取）——两者方向不同、互补不冲突。
