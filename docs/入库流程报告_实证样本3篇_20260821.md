## 二、场景适配判断

文枢 `文献导入.md` §2 区分两类路径：本流水线 §7 覆盖"整本 PDF（书籍级）→ 分篇"；**单篇/小批文献走单篇入库**。本次样本恰好横跨两类，处理策略：

| 文件 | 类型 | 篇目映射 | 锚点空间 |
|---|---|---|---|
| 《四渡》PDF | 单篇期刊论文 | 整篇 = 1 篇 | `^v00p{页}`（3 锚点） |
| "过滤气泡"PDF | 单篇期刊论文 | 整篇 = 1 篇 | `^v00p{页}`（4 锚点） |
| 倦怠社会 EPUB | 整本专著 | 拆章 = 9 篇 | `^v01p{段}`（392 锚点） |

**关键点**：
- 两篇论文无目录页、无多篇结构，S2 目录解析对单篇退化为"整篇识别"，偏移恒 0，分篇=整篇。
- EPUB 无 PDF 页概念，用 ebooklib 拆章 + `filepos` 锚点定位章节边界，段号替代页码作锚点空间。

## 五、关键发现 / 经验教训

1. **六段流水线对"单篇论文"天然适配**：单篇论文=1 篇目、偏移0、整篇切分，六段脚本无需改动即可跑通，S6 全绿。
2. **EPUB 是本次主要适配成本**：无 PDF 页码 → 段号锚点空间；标题用 `<font size>` 而非 h 标签；`[n]` 脚注为噪声。**建议未来为 EPUB 补一个专用拆章脚本**（当前用临时脚本）。
3. **图谱断点续跑有效**：`外二篇`（203 段大章）首次 3 次重试失败，用 `--titles "外二篇"` 续跑成功补抽（13 实体/12 关系），不影响整体。
4. **锚点溯源闭环**：回答每条引用锚点均回原文核验通过，无编造，符合文枢合规红线。
5. **观察项**：图谱问答中 LLM 因 top-k 命中"外二篇"引文块偏多，回答尾部出现保守"依据有限"提示（实际有完整正文）。可增大 `--top-k` 或调块粒度改善，非图谱问题。

## 八、P0 优化补记（2026-08-21，同日完成）

针对本报告遗留问题，完成两项 P0 优化并回归验证：

### 8.1 固化 EPUB 拆章脚本（scripts/epub_split.py）

- **原问题**：EPUB 拆章为会话临时脚本，SKILL.md 宣称支持 EPUB 但 scripts/ 无正式工具。
- **固化内容**：`epub_split.py` 参数化（--input/--output/--volume/--keep-footnotes），toc 标题顺序定位切分（filepos 偏移实测不可靠，弃用），非正文黑名单（扉页/目录/版权页），`[n]` 脚注默认清理，标题行剔除（防 strip_header 误删）。
- **回归结果**（倦怠社会）：9 章 / 272 段 / 质量门 **0 issue 0 warning** / 锚点 9/9 从 0001 起。清理 `[n]` 后 282 段（保留脚注 402 段 ≈ 原 392 段，吻合）。

### 8.2 单篇/小批文献自动路径（toc_parse --single）

- **原问题**：单篇论文需人工构造 manifest 绕过"篇目 ≥5"哨兵。
- **固化内容**：`toc_parse.py --single [标题]` 整篇 = 1 篇、偏移 0；自动取标题过滤期刊页眉（表格管道符/期卷号）；`--min-works` 哨兵可调。
- **回归结果**：左衡《四渡》3 锚点 / 赵政《过滤气泡》4 锚点，全链路 0 issue 0 warning，与人工路径结果一致。

### 8.3 状态

遗留问题 #1（[n] 脚注）已由 8.1 解决；#2（外二篇大篇）保留；#3（期刊页眉）保留。P1（大章分段/图谱续跑）视后续迭代。

### 8.4 P1 优化补记（2026-08-21）

1. **大块自动分段**（`split_long_block`）：索引构建时超长块按句边界拆分为 ≤900 字粒度（无句号兜底硬切），缓解"外二篇 203 段大块导致 top-k 命中偏斜、回答尾部误报依据不足"的观察项；锚点不变（同 anchor 多块），仅影响检索粒度。
